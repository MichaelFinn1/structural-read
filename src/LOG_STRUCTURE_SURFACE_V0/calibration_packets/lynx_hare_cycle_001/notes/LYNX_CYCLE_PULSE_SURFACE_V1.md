# LYNX_CYCLE_PULSE_SURFACE_V1

Status:
natural_motion_surface_added

## Purpose

This surface exposes repeated pulse shapes in the lynx temporal series.

It tracks:

- rise start
- peak year
- fall end
- duration
- peak population
- rise slope
- fall slope
- recovery class

## Boundary

This surface does not infer ecological causality.

It does not explain predator-prey mechanics.

It only exposes observer-side pulse morphology in a natural temporal substrate.

## Initial read frame

The useful question is not whether cycles are identical.

The useful question is how pulse shape changes across repetition:

- gradual rise
- sharp fall
- brief peak
- deep return
- partial return
- incomplete return

## Hold

Natural cyclic recurrence is not exact repetition.
It is repeated pulse formation under changing amplitude and recovery conditions.
