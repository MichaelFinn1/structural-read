# LYNX_PULSE_COMPARATIVE_SURFACE_V1

Status:
natural_comparative_motion_surface_added

## Purpose

This surface compares pulse shapes across the lynx cycle surface.

It tracks:

- amplitude class
- rise/fall symmetry
- recovery depth
- pulse shape

## Boundary

This surface does not infer ecological causality.

It does not explain predator-prey mechanics.

It only compares observer-side pulse morphology.

## Hold

Natural pulse recurrence is not exact repetition.

The useful read is how repeated pulses vary in amplitude, asymmetry, and recovery depth.
