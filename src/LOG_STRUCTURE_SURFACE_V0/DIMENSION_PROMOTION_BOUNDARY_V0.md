# DIMENSION_PROMOTION_BOUNDARY_V0

Current rule:

Interesting distinctions are not automatically promoted into architecture.

A distinction should only become a structural dimension if it:

- survives cross-terrain comparison
- remains separable from existing regimes
- repeatedly changes comparative interpretation
- avoids semantic collapse
- preserves reversibility

Current caution:

The system is now coherent enough that premature dimensional expansion may reduce clarity instead of increasing it.

Current pacing:

1. stabilize grammar
2. compare terrains
3. observe recurring ecological combinations
4. watch for repeated independent distinctions
5. only then consider promotion
