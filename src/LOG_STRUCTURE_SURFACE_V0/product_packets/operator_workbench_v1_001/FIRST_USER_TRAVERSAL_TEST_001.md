# FIRST_USER_TRAVERSAL_TEST_001

Status:
operator_workflow_test_plan

## Test purpose

Observe whether one technically competent user can orient inside the workbench loop.

This does not test theory comprehension.

It tests traversal quality.

## User task

Load the Apache comparison basin.

Find one region that appears to have moved away from baseline.

Widen or narrow the view.

Descend once.

Save orientation state.

Return to it.

## Observe

- where the user hesitates
- what they click first
- what they ignore
- what preserves orientation
- what creates overload
- whether descent feels trustworthy
- whether return restores context

## Do not explain upfront

Do not teach the whole grammar.

Only say:

This tool helps compare log surfaces structurally.
It does not infer cause.
You remain the semantic holder.

## Success signals

- user can identify what moved
- user can describe where they descended
- user can recover the saved state
- user does not feel forced into an interpretation
- user asks useful follow-up questions

## Failure signals

- user cannot tell what the map is for
- user treats the output as anomaly detection
- user loses provenance
- user cannot recover descent path
- user sees too much vocabulary
- user asks what the system thinks happened

## Hold

Test orientation, not persuasion.
