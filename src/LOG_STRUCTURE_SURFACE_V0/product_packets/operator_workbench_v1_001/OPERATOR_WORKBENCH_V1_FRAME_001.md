# OPERATOR_WORKBENCH_V1_FRAME_001

Status:
product_transition_frame

## Core distinction

Constitutional substrate != operational workbench.

The substrate remains slow, open-ended, and research-oriented.

The workbench becomes bounded, operational, and testable.

## Product identity

The product is not:

- AI log interpretation
- anomaly detection
- root cause inference
- hidden-state modeling
- semantic authority

The product is:

recoverable comparative orientation for large log surfaces.

## V1 purpose

Help a technically competent user stay oriented while traversing large operational residue surfaces.

The user remains the semantic holder.

The system preserves:

- comparison
- movement
- locality
- provenance
- descent
- stance history
- delayed return

## V1 invariants

Every visible surface must remain replayably descendable.

Every comparison must preserve provenance.

Every stance movement must preserve continuity.

Every saved state must support return.

No semantic interpretation is promoted by default.

## First operational loop

ingest
→ compare
→ widen/narrow
→ descend
→ bookmark state
→ return

## Hard product law

Movement quality matters more than representational richness.

## External vocabulary

Prefer:

- moved
- stable
- detached
- concentrated
- redistributed
- persistent
- returned
- widened
- narrowed

Avoid:

- anomaly

- attack
- hidden state
- intent

## Hold

The workbench helps users preserve orientation under complexity.
It does not replace their judgment about what the complexity means.
