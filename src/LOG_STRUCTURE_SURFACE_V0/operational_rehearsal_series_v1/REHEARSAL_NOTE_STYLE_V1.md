# REHEARSAL_NOTE_STYLE_V1

Record only operational traversal observations.

Good examples:

- lost orientation after widening
- sticky note restored focus quickly
- global pattern over-suggested continuity
- local descent weakened unexpectedly
- raw span mattered more than expected
- return traversal felt stable
- unresolvedness preserved orientation
- constitution shift confused replay
- global climate helped relocation

Avoid:

- semantic interpretation
- anomaly explanation
- hidden cause inference
- topology mythology
- "the system discovered"

The purpose is:
investigatory continuity under interruption and changing reread pressure.
