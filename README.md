# Structural Read

A visual tool for exploring large, messy data before deciding what it means.

## Try it now

Open the interactive preview:

https://michaelfinn1.github.io/structural-read/

If that link is not active yet, download this repository and open:

TRY_NOW.html

## What to do

1. Click an interesting region.
2. Look at the lower view.
3. Use the mouse wheel to change lens size.
4. Save a card.
5. Move somewhere else.
6. Reload the card to return.

Just explore first.
