# RELATIONAL_PERSISTENCE_SYNTHESIS_V0

Status: consolidation_note

## Purpose

Bank the current relational model before adding more extraction.

This is not a final ontology.
This is a current observer synthesis.

## Core correction

Stable, middle, and residual are not isolated bins.

They are adjacent persistence postures inside one structural field.

They can locally touch without becoming stages of one lifecycle.

## Static / postural layer

stable
=
persistence mass geometry

middle
=
contextual reuse topology

residual
=
edge variation ecology

These describe how persistence inhabits context inside a bounded read.

## Dynamic / movement layer

transition
=
movement between persistence regimes across windows

Transition remains separate from posture.

Do not use transition as a hidden truth layer.

## Important boundary

Do not read:

residual -> middle -> stable

as a universal developmental ladder.

Safe statement:

Every exact form first appears through the residual gate.

Unsafe statement:

Every residual is on its way to middle or stable.

## Current relational findings

1. Regimes locally touch.

Examples:

stable-residual-stable
middle-stable-middle
residual-residual-residual

These are local contact geometries, not lifecycle claims.

2. Residuals can be structurally embedded without exact recurrence persistence.

Observed forms:

- stable-attached residual clouds
- residual-clustered edge fields
- mixed local neighborhoods

3. Middle persistence can circulate with or without stable anchoring.

Observed contrast:

openssh middle is highly stable-adjacent.
apache_access middle is less stable-adjacent.

4. Persistence exists at multiple resolutions.

- exact-template persistence
- rough-shape persistence
- neighborhood persistence
- attachment persistence
- circulation persistence

## Current model

The architecture is converging toward interacting persistence regimes,
not scalar recurrence bands.

Stable, middle, residual, and transition surfaces expose different but locally interacting persistence geometries.
