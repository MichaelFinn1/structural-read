# COMPARATIVE_REREAD_SESSIONS_V1

Status:
phase_open

## Purpose

Run the same reread conduct across different continuity ecologies.

The purpose is not extracting one hidden structure.

The purpose is observing how investigatory orientation behaves under changing continuity pressures.

## Method

For each session:

1. choose one terrain
2. establish global orientation
3. descend locally
4. save at least one continuity object
5. widen
6. compare local/global relation
7. note unresolvedness
8. return later if needed

## Current focus

- interruption survivability
- widening distortion
- local/global disagreement
- graceful continuity weakening
- over-coherence temptation
- replay recoverability

## Boundary

Do not force equivalence across terrains.

Different continuity ecologies may preserve orientation differently.

## Hold

Comparative reread is procedural comparison, not ontology fusion.
