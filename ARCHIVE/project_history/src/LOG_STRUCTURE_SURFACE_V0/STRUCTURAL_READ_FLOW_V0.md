# STRUCTURAL_READ_FLOW_V0

Status: product_flow_spine

## Purpose

Define the first clean product flow for Structural Read.

This is not a dashboard.
This is not monitoring.
This is not interpretation.

It is a structural profile sheet workflow.

## Flow

1. Receive

What came in?

- folder path
- files found
- line counts
- file sizes
- log-like surfaces

2. Reduce

What structure appears after recurrence reduction?

- repeated structures
- middle recurrence
- residual lines
- template counts
- band proportions

3. Profile

What can be seen without interpretation?

- file-level profile bars
- stable / middle / residual texture
- line-volume differences
- template density
- concentration / dispersion

4. Export

What can the user take away?

- CSV surfaces
- Markdown reads
- HTML profile sheets
- slices for Excel / Python / SPSS / R

## Boundary

Structural Read does not:

- infer incidents
- rank severity
- assign cause
- recommend action
- claim anomaly
- replace domain judgment

## One-line hold

Receive the terrain, reduce recurrence, profile structure, export usable surfaces.
