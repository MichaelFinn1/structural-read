# FAILURE_TERRAIN_PLAN_V1

Status:
planned_not_run

## Purpose

Create a small set of terrains that pressure orientation without rewarding beautiful morphology.

Failure terrains test whether the observer stack preserves restraint when structure is weak, misleading, interrupted, or unstable.

## Candidate terrains

1. pseudo_periodic_noise
- repeated weak motifs
- misleading local cadence
- should test false continuity

2. interrupted_carrier
- long carrier regions with missing spans
- should test replay gaps and return stability

3. oscillating_regime
- alternating stable/residual dominance
- should test constitution-local coherence

4. sparse_burst_field
- mostly flat carrier with rare burst clusters
- should test local descent discipline

5. drift_without_anchor
- slow change with no durable local anchor
- should test refusal to invent persistence

## Boundary

These terrains are not proof terrains.

They are stress terrains.

They should reveal where the stack preserves orientation, where it weakens claims, and where it refuses coherence.

## Hold

Failure to form rich morphology is a valid result.
