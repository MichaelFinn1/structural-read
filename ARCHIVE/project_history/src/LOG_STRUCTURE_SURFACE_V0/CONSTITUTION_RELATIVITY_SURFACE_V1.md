# CONSTITUTION_RELATIVITY_SURFACE_V1

Status:
observer_side_constitution_surface

## Purpose

This surface tracks how local reread posture changes under widening constitutions.

It separates:

- terrain-relative change
- observer-relative admissibility change

without claiming object identity.

## What it measures

- local region
- dominant posture
- continuity strength
- transition pressure
- survival class

## Survival classes

- holds
- weakens
- recomposes
- dissolves
- reappears_or_recolors
- ambiguous

## Boundary

This surface does not infer:

- true feature identity
- causal deformation
- semantic meaning
- privileged window size
- hidden process

## Hold

A constitution creates a continuity context.  
Reread deformation is partly terrain-relative and partly observer-relative.
