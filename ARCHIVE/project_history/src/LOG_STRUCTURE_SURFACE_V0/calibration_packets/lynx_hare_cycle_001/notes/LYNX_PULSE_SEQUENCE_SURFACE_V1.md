# LYNX_PULSE_SEQUENCE_SURFACE_V1

Status:
natural_pulse_sequence_surface_added

## Purpose

This surface compares pulse-to-pulse deformation across the lynx cycle series.

It tracks:

- previous pulse shape
- current pulse shape
- amplitude shift
- recovery shift
- transition class

## Boundary

This does not infer ecological cause.

It does not create a cycle grammar.

It only records observer-side continuity deformation between adjacent natural pulses.

## Hold

Repeated pulse recurrence is not exact repetition.

The useful question is how pulse morphology changes from one cycle to the next while preserving edge cases and open continuations.
