# OPERATIONAL_REHEARSAL_SERIES_V1

Status:
phase_open

## Purpose

Run small investigatory rehearsals using the existing traversal surface.

The purpose is not semantic interpretation.

The purpose is testing whether investigatory orientation survives:

- interruption
- widening
- local confusion
- sparse continuity
- false coherence
- return traversal

## Current workbench loop

global orientation
→ local descent
→ raw selection
→ sticky note
→ saved card
→ interruption
→ reload
→ return traversal

## What is being evaluated

- orientation continuity
- replay survivability
- investigatory provenance
- local/global coordination
- unresolved preservation
- lawful non-recovery

## What is NOT being evaluated

- anomaly detection
- semantic diagnosis
- root-cause inference
- predictive interpretation

## Hold

The operator remains primary.

The workbench scaffolds investigatory continuity.
It does not replace judgment.

Non-recovery remains fully admissible.
