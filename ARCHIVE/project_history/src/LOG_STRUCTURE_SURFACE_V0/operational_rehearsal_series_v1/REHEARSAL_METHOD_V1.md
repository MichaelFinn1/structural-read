# REHEARSAL_METHOD_V1

For each rehearsal:

1. Begin from global map.
2. Identify one region of interest.
3. Descend locally.
4. Select raw span.
5. Write sticky note.
6. Save card.
7. Move away completely.
8. Return only through saved card.
9. Observe whether investigatory orientation survives.

Record only:

- what preserved the thread
- what weakened orientation
- what became confusing
- what felt operationally useful
- what remained unresolved
- whether non-recovery appeared lawful

Do not attempt semantic interpretation.

The purpose is investigatory continuity under changing reread conditions.
