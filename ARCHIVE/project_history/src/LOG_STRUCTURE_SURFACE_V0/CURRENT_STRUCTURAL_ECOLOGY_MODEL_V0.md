# CURRENT_STRUCTURAL_ECOLOGY_MODEL_V0

Status: current_model_bank

## Purpose

Bank the current structural ecology model before adding more extraction, datasets, or visualization.

## Core correction

Stable, middle, and residual are not value levels.

They are adjacent persistence regimes inside one structural field.

They are not a simple ladder.

Do not read them as:

residual -> middle -> stable

except as one possible movement path among others.

## Static posture layer

Static posture asks:

What is the recurrence state in this bounded read?

Current regimes:

stable
=
persistent recurrence mass and accumulation shape

middle
=
weak recurrence and contextual reuse topology

residual
=
edge rarity ecology, rough-shape families, and local attachment

absence
=
outside the currently observed recurrence field

## Dynamic transition layer

Transition asks:

How does recurrence posture change across windows?

Possible movements include:

absent -> residual
residual -> middle
middle -> stable
stable -> middle
middle -> residual
residual -> absent

But these are not lifecycle stages.

Some residual forms may remain edge variation.
Some middle forms may circulate without anchoring.
Some stable forms may fragment.
Some rough-shape families may persist without exact-template recurrence.

## Key current findings

1. Singleton does not mean structurally isolated.

Residual exact forms may still participate in:

- rough-shape persistence
- local attachment
- edge-cloud circulation
- contextual resemblance

2. Higher recurrence does not imply stronger contextual anchoring.

Middle bucket 4 can be dominated by:

1-1-1-1

which means repeated occurrence through distinct neighborhoods.

3. Persistence exists at multiple resolutions:

- exact-template persistence
- rough-shape persistence
- neighborhood persistence
- attachment persistence
- circulation persistence

Counts remain useful, but they are one projection of persistence, not the whole structure.
