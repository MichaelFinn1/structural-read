# STRUCTURAL_READ_LAYER_MODEL_V0

Status: observer_contract

## Purpose

Hold the current layer model without adding interpretation.

## Layers

Stable:
Persistent recurrence mass.
Shows recurrence floor, concentration, slope, and compression shape.

Middle:
Weak recurrence ecology.
Shows count buckets and contextual reuse topology.

Residual:
Sparse edge field.
Shows insufficient recurrence in the current bounded read.

Transition:
Windowed recurrence movement.
Shows candidate movement between recurrence postures without lifecycle claims.

## Current refinement

Recurrence persistence and contextual reuse topology are independent axes.

A form can recur more often while remaining contextually mobile.

## Product boundary

Structural Read supports orientation before interpretation.

It does not infer anomaly, severity, cause, importance, lifecycle, semantic family, or recommended action.

## One-line hold

Stable shows recurrence terrain; middle shows contextual circulation; residual preserves sparse edge structure; transition shows movement between postures.
