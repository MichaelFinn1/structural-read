# PROVISIONAL_ECOLOGY_VOCABULARY_V0

Status: provisional_vocabulary_note

## Purpose

This note records current observer-side morphology terms.

These are reread compressions.

They are not ontology.
They are not semantic states.
They are not system truths.

## Current provisional terms

### braided coexistence

Use when:

multiple regimes repeatedly participate locally
without full regime collapse.

Current example:

Thunderbird:
persistent local braided coupling regions within a still-structured terrain.

### residual islanding

Use when:

residual forms show strong self-adjacency
and weak stable attachment.

Current example:

Linux:
diffuse residual self-adjacent islanding beside strongly enclosed stable terrain.

### stable enclosure

Use when:

stable forms remain strongly self-adjacent
and dominate local recurrence terrain.

Current examples:

Linux and HDFS.

### bounded middle participation

Use when:

middle participation persists,
but remains bounded inside a stable-dominant terrain.

Current example:

HDFS.

### attached residual spill

Use when:

residual forms are strongly near stable terrain
rather than self-islanded.

Current example:

HDFS.

## Vocabulary boundary

Terms remain usable only while they remain:

- descendable
- revisable
- local
- observer-side
- non-semantic

Do not use these terms as:

- diagnoses
- causes
- stages
- lifecycle states
- anomaly classes
- hidden state names

## Current hold

Vocabulary is shorthand for reread posture,
not a substitute for descent.
