# WORKBENCH_CONSTITUTION_V1

Status:
constitutional_floor_draft

## Purpose

The workbench is a staged investigatory traversal apparatus.

It is not:
- an answer engine
- a recommendation engine
- a semantic classifier
- an optimization dashboard

It is:
- a lawful reread environment
- a bounded descent surface
- a replay-preserving investigatory structure

---

# SECTION 0 — Terrain Admission

Purpose:
declare investigatory scope before traversal.

Allowed:
- select log folder
- define start/end brackets
- confirm terrain admission

Preserved:
- explicit terrain boundary
- replayable scope

Forbidden drift:
- implicit scope
- auto-descent before admission
- hidden terrain expansion

---

# SECTION 1 — Global Lens

Purpose:
establish broad continuity climate.

Allowed:
- lens resizing
- lens movement
- terrain-scale reread

Preserved:
- broad organizational continuity
- replayable constitution

Forbidden drift:
- semantic interpretation
- hidden recommendations
- automatic "best scale"

---

# SECTION 2 — Focus Lens

Purpose:
project lawful local reread from global terrain.

Allowed:
- local span descent
- local redistribution inspection
- focus-relative replay

Preserved:
- explicit projection relation
- continuity of descent

Forbidden drift:
- disconnected local inspection
- arbitrary zoom recursion

---

# SECTION 3 — Evidence Descent

Purpose:
transform terrain span into temporal evidence sequence.

Invariant:
same temporal order
different observational posture

Allowed:
- raw line inspection
- local evidence selection
- packet inclusion

Forbidden drift:
- semantic relabeling
- inferred causality

# Constitutional Boundary

The workbench may accumulate:
- replay behavior
- survivability behavior
- fragmentation behavior
- continuity persistence
- widening/narrowing transitions

But must not:
- recommend correct scales
- claim ideal constitutions
- impose interpretive authority
