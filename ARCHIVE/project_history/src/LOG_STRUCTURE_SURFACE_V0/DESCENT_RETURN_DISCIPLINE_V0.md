# DESCENT_RETURN_DISCIPLINE_V0

Status: active_method_note

## Core rule

No claim without a descent path.
No descent without a return note.
No return note without a boundary.

## Purpose

This note defines bounded structural rereading.

The observer may move upward into terrain/ecology language only if the path downward remains recoverable.

The observer may move downward into evidence only if it returns with a bounded read.

## Packet question boundary

Packets ask structural questions only.

Allowed:
- Does the read descend cleanly?
- What evidence supports it?
- What weakens under contact?
- What remains unresolved?
- Does the structure survive scale/reread?
- Is the texture attached, islanded, porous, braided, or enclosure-heavy?

Not allowed:
- cause
- anomaly
- intent
- lifecycle
- diagnosis
- hidden system state
- operational explanation as certainty

## Return questions

Each packet must end by answering:

- What evidence was touched?
- What held?
- What weakened?
- What changed?
- What remains unresolved?
- Bank, revise, or stop?

## Boundary

Descent packets are temporary bounded work containers.

They are not permanent ontology objects.
They are not incidents.
They are not entities.
They are not truth claims.

## Current hold

Move down to recover evidence.
Move up only with what survived contact.
