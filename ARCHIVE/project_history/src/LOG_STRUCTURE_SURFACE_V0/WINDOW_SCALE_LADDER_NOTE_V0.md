# WINDOW_SCALE_LADDER_NOTE_V0

Status: active_method_note

## Core rule

Window size is observer stance, not truth-resolution.

A window does not reveal the true scale of the system.
It asks a bounded structural question.

## Current ladder

tight = 250
fine texture / local pulses

middle = 500
regional coherence / merged event

wide = 1000
broad climate / smoothing field

## Scale questions

Ask:

- Does this structure appear only at tight scale?
- Does it survive into middle scale?
- Does it disappear at wide scale?
- Does wide scale preserve background pressure?
- Does tight scale split one middle event into several pulses?
- Does middle scale merge tight pulses into a coherent regional event?

## Reading rule

Use at least two scales before calling something structurally interesting.

Use three scales before calling it scale-sensitive.

## Current pattern

For the openssh participation climate surface:

250:
two localized permeability pulses become visible.

500:
one coherent localized inversion basin appears.

1000:
no inversion basin appears, but broad permeability traces remain visible.

Observer-safe read:

locally strong
regionally coherent
globally non-dominant

## Boundary

Do not treat window size as:
- truth
- hierarchy
- maturity
- resolution superiority
- hidden system scale

Do not infer:
- object movement
- lifecycle
- causality
- anomaly
- system intent

## Current hold

Structure is read by reslicing survival, splitting, merging, and smoothing across source-line regions.

Window sizes are stances for asking different scale questions.
