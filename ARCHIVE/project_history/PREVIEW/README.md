# Structural Read Preview

Start here.

Open:

PREVIEW/OpenStack.html

This is the current simplified preview entry point.

Suggested first session:

1. Survey the terrain.
2. Pick a region.
3. Inspect locally.
4. Open raw lines.
5. Save a card.
6. Move elsewhere.
7. Return using the card.

Focus on whether the workbench helps preserve orientation while understanding is still forming.

Do not start by exploring the full src folder.

The deeper repository contains development history, generated surfaces, calibration packets, and experimental material.

For first feedback, use only this PREVIEW folder plus README.md, GETTING_STARTED.md, and FEEDBACK_REQUEST.md.
