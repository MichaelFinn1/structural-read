2. Survey the global view.
3. Choose a region.
4. Use the focus view.
5. Inspect raw lines.
6. Save a sticky-note card.
7. Move somewhere else.
8. Return using the card.
9. Try comparing two saved cards.

2. Did it help you stay oriented?
3. Did local descent feel useful?
4. Did saved cards help re-entry?
5. Was the card comparison useful or confusing?
6. What did you expect that was missing?
7. What felt unnecessary?

## Important boundary

This is not trying to automate interpretation.

The question is whether the workbench helps preserve investigability while understanding is still forming.
