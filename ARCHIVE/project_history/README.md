# Structural Read

Structural Read is an early workbench for preserving investigability while understanding is still forming.

It is not an anomaly detector, root-cause engine, AI agent, or automated interpretation system.

It helps a person move through large log terrains while preserving:

- orientation
- local inspection
- comparisons
- uncertainty
- investigation paths
- return points

## What it currently does

The current focus lens supports:

- global context view
- local focus view
- raw line inspection
- sticky-note cards
- return/re-entry to saved regions
- coarse region signatures
- card-to-card comparison

## Suggested first session

1. Survey the terrain.
2. Pick a region.
3. Inspect locally.
4. Save a card.
5. Move elsewhere.
6. Return using the card.

If those six steps make sense, the core loop is working.

## How to think about the views

The global view provides context for local investigation.

The focus view is where local structure becomes inspectable.

These are not claims about hidden truth. They are investigation surfaces.

## What this is not

Structural Read does not currently:

- detect anomalies
- infer root cause
- classify incidents
- explain system behavior
- replace operator judgment
- decide what matters

It preserves an investigation path so a human can continue thinking clearly.
