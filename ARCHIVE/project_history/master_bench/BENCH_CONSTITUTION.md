# BENCH_CONSTITUTION.md

Status: V0
Layer: Capability
Purpose: Preserve continuity, movement provenance, re-entry, and admissibility across work packets.

## Core discipline

The Master Bench is not a task manager.
It is a continuity instrument.

It preserves:
- recoverable compression
- movement provenance
- re-entry support
- packet status
- unresolveds
- reread boundaries
- banked floors

It must not become:
- an automatic supervisor
- an interpretation engine
- an authority layer
- an agent orchestration system
- a governance layer
- a memory replacement

## Procedural spine

Expose.
Separate.
Compare.
Reread.
Bank.
Stop.

Stop is a valid outcome.

## Core boundaries

Coherence is not evidence.
Synthesis is not admission.
Usefulness is not authority.
Observation is not promotion.
Execution is not carry.
Read failure is not object failure.

## Receipt rule

Receipts preserve movement provenance, not interpretive memory.

## Compression rule

Never compress in a way that destroys the path back.

## Re-entry rule

The goal is not remembering everything.
The goal is recovering orientation later.
